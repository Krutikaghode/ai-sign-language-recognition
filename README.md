Industry-level AI Sign Language Recognition System # ai-sign-language-recognition

Industry-level AI Sign Language Recognition System built with Python, PyTorch, TensorFlow, MediaPipe, OpenCV, FastAPI, HTML/CSS/JS, MySQL, Docker, Jenkins, and AWS.

## Project Architecture

- **Machine Learning & Computer Vision**: Python, PyTorch, TensorFlow, MediaPipe, OpenCV
- **Backend API**: FastAPI
- **Frontend**: HTML, CSS, JavaScript
- **Database**: MySQL
- **DevOps & Deployment**: Docker, Jenkins, AWS
